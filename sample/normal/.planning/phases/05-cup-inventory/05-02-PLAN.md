# Plan 05-02: Ask for a Restock Before Running Dry

## Goal

The robot raises a restock request while there are still cups left to serve.

## Tasks

1. [ ] Track the cup count against the day's order rate
2. [ ] Post a restock request at two hours of remaining supply
3. [ ] Suppress duplicate requests until the shelf refills

## Acceptance

- Request fires before the shelf empties on 5 simulated days
- At most one open request at a time
